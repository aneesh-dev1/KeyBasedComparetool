Performance guidance

Sort batches flush at the row limit or memory budget, whichever comes first. Comparison streams rows; its batch size controls progress reporting. Duplicate keys generate a warning and audit; only the selected occurrence is compared.

For a 32 GB machine, start with 4 GB and parallel sorting on a local SSD. The budget is shared across sort workers; it is not a hard limit on total RAM. Use sequential sorting on a slow disk.

Keys must be nonempty. Duplicate rows are reported and skipped.
Case, spaces and number formatting are compared exactly.

Start here

Setup & first comparison

On Windows, install 64-bit Python 3.10 or newer, extract the complete app folder, and run Start CSV Compare.bat. Keep the terminal open while using the app. On macOS, use Start CSV Compare.command. No third-party Python packages are required.

  1. Open New comparison and select two CSV, .xlsx, or .xlsm files. For older .xls files, save them as .xlsx first.
  2. Choose CSV delimiter and encoding, then upload. For Excel, select one worksheet per workbook and wait for import.
  3. Review Column headers, choose your keys and scope, add optional value overrides, and preview the source values.
  4. Start comparison, follow Pipeline & logs, then review Results, use Analysis to explore mismatches by key or column, and download reports.

Prepare your data

Column headers & keys

Column headers match ignoring case. AT01S and at01s match automatically. For different names, such as AT01S and AT02S, rename either header in Column headers and apply. Results use file 1 spelling. These edits do not rewrite your source files.

  1. Column order may differ. Only headers shared by both files are compared. Non-common columns are excluded automatically; rename a header to bring it into scope.
  2. CSV blank headers become column1, column2, etc. Duplicate names get numeric suffixes. Excel requires a nonempty, unique header row.
  3. Choose one or more columns that uniquely identify a row. Composite keys use the selected column order. Duplicate keys generate warnings and use the selected first/last occurrence. Empty key components stop the comparison.
  4. Header matching ignores case, but cell values and key values remain exact: 001 differs from 1, and None differs from none.

Set comparison rules

Ignored columns, keys & value overrides

Use scope settings to control what the comparison tests. Keep key columns included so rows can still be matched.

  1. Ignore columns: search the loaded header list and select non-key columns. This does not scan the full file.
  2. Ignore key containers: create a name, reason, and key values in the sidebar, then select the container in Keys & scope. Excluded rows are removed from both sides before comparison.
  3. Manual single keys: enter 001,002,003. Quote values containing commas or leading spaces. Composite keys use JSON tuples such as [["001","A"],["002","B"]].
  4. Value overrides: select a column and a directional pair, for example file 1 None and file 2 none. That pair counts as equivalent for that column only; original values are preserved.

Work with large files

6 GB files on a 32 GB Windows machine

Begin with the 4 GB total sort memory setting and parallel sorting on a local SSD. This budget is shared by the workers; it is not a hard limit on total application RAM. Actual runtime depends on data, storage, CPU, and output size.

  1. CSV uploads stream in 8 MB chunks. Pause or resume an interrupted upload with the same filenames and sizes.
  2. Comparison creates sorted batches on disk and merges them by key, rather than loading both complete CSVs into memory.
  3. Reserve space for both uploaded files, temporary sort runs, and reports. Two 6 GB uploads alone require 12 GB, before scratch and output space. Keep the original source files in mind too.
  4. Choose sequential sorting on a slow or shared disk. The live console reports batch starts, completion, processed rows, and comparison stages.
  5. Excel worksheets are imported into local CSVs first. The original workbook, imported data, scratch files, and results all need disk space.

Review & export

Previews, results & job history

Source preview reads only the requested first 1–1,000 rows, showing 20 columns at a time. Source preview values are limited to 500 characters and responses to 2 MB. Result previews show up to 100 records with values shortened to 1,000 characters.

  1. Excel export creates one sheet per mismatched column. Ten columns with differences produce ten mismatch sheets, plus File Summary and a linked TOC with match rates and an editable Comments column. Each mismatch sheet has a Back to TOC link. Configured key exclusions add an Ignored key containers audit sheet.
  2. Sheet names are sanitized and shortened to meet Excel limits. A column sheet supports up to 1,048,574 mismatch records (the export reserves space for report headers); cells cannot exceed 32,767 UTF-16 code units. Use CSV if Excel export exceeds these limits.
  3. Download changed-cell CSV, left-only keys, and right-only keys separately. HTML export is one self-contained TransUnion-styled leadership report with summary metrics, a match-rate pie chart, all mismatching and fully matching columns, expandable samples of up to 20 mismatching keys per column with both values, and complete configured ignored-key container details. Sample values longer than 1,000 characters are shortened and marked. Open the HTML directly; no ZIP or supporting files are needed. Detailed cell mismatches remain in Excel/CSV and Analysis.
  4. Job history reopens saved uploads, configurations, completed comparisons, and reports. CSV/Excel jobs persist in the local data directory.

Compare structured data

Nested JSON & side-by-side results

Paste two JSON documents or upload UTF-8 JSON files. Object property order is ignored. Strings are case-sensitive, types matter, and numbers compare by numeric value. JSON comparison has separate limits from CSV/Excel.

  1. Preserve array order compares items by position. Ignore order matches whole blocks; duplicate items remain significant.
  2. Use Find arrays & choose keys to select a unique field for each detected array, such as students → id. Arrays without a selected key keep their pasted order. Advanced Match by field aligns objects using a unique, non-null direct property such as id. Add a rule for $.customers or a nested array such as $.customers[*].addresses.
  3. Changed unordered blocks without a match field appear as removed and added. Choose a match field to compare changed properties within the same logical record.
  4. Side-by-side results align matched blocks using your rules. Yellow marks changes, red removals, and green additions. Use next/previous difference and the context filter.
  5. Each input is limited to 5 MiB, 100 nesting levels, and 200,000 values. More than 10,000 differences produces an error instead of partial results.
  6. JSON results remain in the current tab until refresh. Download JSON or HTML to retain them. The interactive view pages 200 aligned rows at a time and shortens lines over 2,000 characters; downloads retain full values.

Team workflow: queue, storage, profiles and review

Open Storage & queue to see your workspace's disk usage, queued/running work, and Cancel controls. Active tasks stop at a safe checkpoint; uploads remain until you delete the job. Disk preflight warns before upload but does not reserve space.

Manage profile templates in Profile templates; apply a template in Column headers after upload. Performance and reusable column rules are in Settings. Profiles reuse headers, scope, overrides and rules; saving the same name replaces it. Optional rules in Value overrides can trim whitespace, ignore case, compare numbers within an absolute tolerance, or parse two explicit date formats. Exact text remains the default, and keys always compare exactly.

Analysis supports Expected, Needs investigation and Resolved classifications with comments for a column, key, or both. Save a note and regenerate exports to include it. Duplicate keys produce a warning without failing the comparison. Choose the first or last source occurrence in Keys & scope. Results include counts and a complete duplicate-key CSV audit; Pipeline & logs shows a bounded sample.

Enable completion notifications in Storage & queue. Your browser must allow notifications; remote deployments generally need HTTPS. Keep the page open to receive alerts and use Disable notifications to turn them off.

Resume and mismatch patterns

After a restart, open an interrupted job from Job history and choose Resume from saved sort batches in Pipeline & logs. Source files and saved batches are validated first. Completed sort work is reused; the final comparison starts again from the sorted data. Checkpoints use disk until completion or normal cleanup. Older jobs without checkpoints cannot resume.

In Analysis, Mismatch patterns ranks recurring value changes and shows category counts per column. Patterns explain differences; they do not change results. To accept 0 and 0.00 or -11 and -11.00, select the value column in Value overrides, tick Ignore numeric formatting and save the rule before comparing. Keys stay exact.

Frequently asked questions

Select a question to see the answer.

Are my files uploaded to the cloud?

The browser uploads files to the server hosting this app. For a local launch this is your own computer; for team deployment it is the on-premises server. Uploaded copies and reports stay in its configured data directory. Your original source files are not modified.

Can I compare a CSV file with an Excel worksheet?

Yes. Upload either supported format on each side. Choose a worksheet for any Excel input; the selected data is imported before continuing through the same header and key workflow.

Why does the tool report a column or schema mismatch?

Open Column headers and align unmatched names in either file. Matching ignores case, but spelling and spaces still matter. Only shared column names enter the comparison; unmatched columns are excluded. Blank or duplicate edited headers must be corrected before applying.

How are duplicate and empty keys handled?

Duplicate keys do not stop comparison. The first source row is used by default; you may select the last instead. Extra occurrences are skipped and reported. Choose additional key columns for a composite key when all records need comparison. Empty key components are not accepted for compared rows. Rows explicitly excluded by key are removed before these checks.

Why is 001 different from 1, or None different from none?

CSV/Excel values are compared as exact text. Leading zeros, whitespace, case, and numeric formatting are significant. Add a value override for a specific acceptable pair. JSON numbers use numeric equality, while JSON strings still compare exactly.

How do Excel formulas, dates, and formatting behave?

Excel comparison uses stored values, not display formatting. Dates stored as numbers compare as Excel serial values; booleans become TRUE/FALSE. Cached formula results are used without recalculating. If a formula has no saved result, recalculate and save the workbook in Excel first. Macros are not executed.

The browser cannot connect. How do I start the app?

Run the platform launcher and keep its console open. Use the localhost URL printed in that console; the default port is 8765, but a custom launch may use another port such as 8766. If the console reports an error, resolve it before refreshing the browser.

Upload stopped. Do I have to begin again?

For an unfinished CSV/Excel upload, reopen it in Job history and reselect the same two files with matching filenames and sizes, then resume. Do not change their contents between attempts. The app keeps the uploaded file length as its checkpoint.

What should I do about a Windows permission denied error?

Check that the data folder is writable and on a local drive. Close applications holding files in that folder, and avoid synced or network folders for scratch data. The app retries transient file-lock conflicts. If the error persists, inspect the console log and your folder permissions; do not delete files belonging to an active job.

How long will two 6 GB files take?

There is no fixed time estimate without a benchmark on your Windows machine and actual data. Sort memory, SSD speed, column width, and the number of mismatches affect runtime. Start with a representative sample and use Pipeline & logs to follow the full run.

How do I clean up uploaded files?

Use Delete in Job history to permanently remove a job and its uploaded copies, scratch data, logs and reports. Download needed reports first. Original files on your computer are unchanged. Automatic cleanup runs at startup and hourly; the default retention is 7 days of inactivity. Running or queued comparisons, imports, exports and active requests are protected. Your administrator can change retention or disable it with RETENTION_DAYS=0.

Why is my report larger than expected?

Every mismatched cell is a result record, so a wide file with many changed values can produce far more output records than input rows. Download only the formats you need and reserve additional disk space for export.

Why are some rows absent from the mismatch sheets?

Column mismatch sheets include changed cells for keys present in both files. Rows found on one side only are in the left-only or right-only downloads. Ignored keys and ignored columns are excluded from mismatch testing.

Why do reordered JSON blocks show removed and added entries?

In Ignore order mode, blocks match only when their contents are equivalent under your array rules. For changed objects representing the same record, add a Match by field rule with a unique, non-null property such as id.

Can I navigate away while a comparison is running?

Yes. Open Docs & FAQ, JSON comparison, containers, or Job history while the local comparison worker runs. Keep the server console running. Completed CSV/Excel jobs remain available in Job history. JSON inputs and results are not saved there.

How do I expand the sidebar?

Use the expand control at the bottom of the icon rail. Hover or keyboard-focus icons to see labels. On smaller screens, the expanded sidebar is a drawer: select a destination, click outside, or press Escape to close it.

Match array items by key

Find arrays in both inputs, then choose a key for each one. For example, choose id for students to match Jim, Dwight and Kevin even when their order changes. Each array can use a different key.

Arrays keep their pasted order until you choose a key.

Advanced array rules

Array rules

Override the default for a specific array. Use $ for a root array, $.customers, or $.customers[*].addresses. Use $["property.with.dots"] for special property names. Match fields are direct properties, such as id.

Without a match field, changed blocks in unordered arrays appear as removed and added. Match fields must be unique and non-null within each array.

Matched blocks are aligned using your array rules. Line numbers and paths refer to each pretty-printed original input; aligned blocks may appear in a different order. Yellow = changed, red = removed, green = added. Source JSON stays unchanged.
